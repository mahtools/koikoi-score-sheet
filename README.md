## 📝 About 📝
Koi-koi score-sheet is a small single-file app that can be used in real-life play to track the scores of an ongoing game.

As it's a single-file app, it can easily be hosted in any browser offline or used through [Github pages](https://mahtools.github.io/koikoi-score-sheet/).

## 🌐 Use online 🌐
You can head over to the [Github Pages](https://mahtools.github.io/koikoi-score-sheet/) site and start using the app. 

Once opened it has no dependency on a stable internet connection to keep working.

## 🚫🌐 Use offline 🌐🚫
The app is contained within a single html file. Download the file from the [master branch](https://github.com/mahtools/koikoi-score-sheet/blob/master/index.html) or from the [releases tab](https://github.com/mahtools/koikoi-score-sheet/releases) and run it inside your preferred web browser.

## 🕹️ Controls 🕹️
1. Input the length of game you would like to play at the bottom of the page and click `勝負/Go`
2. Play Koi-koi and input the score of each hand in each field 🙂

The `Oya` is the dealer, and the `Ko` is the player.
